# LFTC
Mor cu materia asta


I made the lexical scanner in Python with regex, Symbol Table with a Hash Table with Coalescing,
buckets, the hash is the sum of the ASCII code of every symbol present. The lexical scanner is divided in 5 categories: keywords, 
operators, separators, identifiers and constants. I used 3 output files in order to see if there are any errors, the state of the Symbol Table and the Hash Table itself. 
In token.in there are all the expressions used.
